# Challenge-08

Aplicacion Movil de Mapas con la funcionalidad de usarse en movimiento mediante sensores y camara, y la deteccion automatica de ubicacion y de lugares cercanos a este, realizado con Ionic React + Capacitor

Aplicación móvil creada con Ionic React + Capacitor para geolocalización, mapas, sensores, historial local y cámara con marca de agua.








## Instalación

```bash
npm install
ionic serve
```
