# Challenge 09 - Demo con Lovable App de sensores y deteccion de movimientos
Demo planteada por lovable publicada: https://challenge09.lovable.app 

## La aplicacion demo fue hecha con lovable, y se mejoro para su buena implementacion en dispositivos moviles, sin tocar el diseño original y lo propuesto por Lovable

## El funcionamiento propuesto busca que el usuario guarde y grabe movimientos con una etiqueta, para posteriormente probar la prediccion de la APP con un nuevo movimiento, la aplicacion se encargara de analizar si se encuentran similutdes con alguna etiqueta guardada anteriormente. (La APP usa comparacion con similitud).
