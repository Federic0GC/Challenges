## Cómo ejecutar

1. Clona el repositorio
2. Instala dependencias: `npm install`
3. Ejecuta en modo desarrollo: `ionic serve`

## Cómo ejecutarlo en tu celular Android (APK)

1. Genera el APK desde Android Studio:
   - Ve a **Build > Build APK(s)** y espera a que termine.
   - Busca el archivo generado en `android/app/build/outputs/apk/debug/app-debug.apk`.
2. Copia el APK a tu celular (por USB, Google Drive, correo, etc.).
3. En tu celular, abre el archivo APK y acepta la instalación (puede que debas permitir "Instalar apps de fuentes desconocidas").
4. ¡Listo! Ahora puedes usar la app como cualquier otra aplicación instalada.

> También puedes compilar y abrir la app directamente desde Android Studio conectando tu celular por USB y usando el botón ▶️ (Play).
